# AutoCosto

App Android para registrar el uso, los costos y la mantención de tu auto. Tus datos quedan solo en tu teléfono.

Aquí solo se publican las versiones para instalar (no el código).

## Instalar

1. En el teléfono, descarga **[AutoCosto.apk](https://github.com/HanSolito27/autocosto-app/releases/latest/download/AutoCosto.apk)**.
2. Ábrelo. Si Android lo pide, permite instalar apps desde esa aplicación (Chrome, Drive o Mis Archivos).
3. Si Play Protect avisa que es una app desconocida: **Más detalles › Instalar de todas formas**.
4. Abre AutoCosto, escribe tu nombre y registra tu auto.
5. Sigue la guía de **Más › Configurar Samsung** para que los viajes no se corten.

## Actualizar

La app se actualiza sola por internet. Cuando haya que instalar una versión nueva, la app lo avisa en Inicio: toca **Descargar** e instálala encima. Tus datos se mantienen.
